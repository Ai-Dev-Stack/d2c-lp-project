# Power BI ダッシュボード設計書(更新版)

対象:LP・診断アプリのアクセス分析(`analysis/session_data.csv`, `channel_ad_cost.csv`)

> **更新履歴**:当初の設計書(キャンバス1280×720前提)から、実装時に判明した問題を踏まえて全面的に更新した。主な変更点は「キャンバスサイズを1920×1080に変更」「DAXの組み方を単純化」「ファネル用テーブルの作り方を変更」の3点。

---

## 1. 目的

`funnel_analysis.ipynb`で行ったPythonでの分析結果を、インタラクティブに触って確認できるダッシュボードとして再構築する。用途は2つ。

1. 施策の意思決定者が、期間・チャネルを自分で絞り込みながら状況を確認できるようにする
2. ポートフォリオとして「BIツールの運用ができる」ことを示す

---

## 2. データモデル

### 2-1. 読み込むテーブル

| テーブル名 | 由来 | 役割 |
|---|---|---|
| `session_data` | `session_data.csv` | ファクトテーブル(1行=1セッション) |
| `channel_ad_cost` | `channel_ad_cost.csv` | チャネル別の広告費 |
| `FunnelSteps` | Power BI内で手入力 | ファネルチャート専用の補助テーブル(2-4参照) |

### 2-2. リレーション

```
channel_ad_cost[channel]  (1)  ---  (多)  session_data[channel]
```

クロスフィルターの方向は「単一」(`channel_ad_cost`→`session_data`)。この向きのため、**チャネルを軸やスライサーに使うときは、必ず`channel_ad_cost[channel]`を使う**。`session_data[channel]`を使うと、広告費側にフィルターがかからずCPAの計算がずれる。

`FunnelSteps`は他のテーブルとリレーションを作らない(2-4のメジューで代用するため)。

### 2-3. 計算列

`session_data`に、表示用のラベル列を1つ追加している。

```dax
診断状態 = IF(session_data[diagnostic_completed] = 1, "診断完了", "診断未完了")
```

マトリックスなどで「0」「1」のままでは分かりにくいため、日本語ラベルに変換する目的で作成した。

### 2-4. FunnelSteps テーブルの作り方(重要な変更点)

当初は`UNION`と`ROW`を組み合わせた1つの複雑なDAX式でテーブルごと生成する設計だったが、**チャットからの貼り付け時に文字が崩れて構文エラーになる**問題が発生したため、以下の方式に変更した。

1. 「ホーム」タブ→「データの入力」で、`ステップ`(テキスト)と`順序`(数値)の2列だけを**手入力**でテーブル化する

   | ステップ | 順序 |
   |---|---|
   | ① LP訪問 | 1 |
   | ② 悩みセクション到達 | 2 |
   | ③ 診断アプリ開始 | 3 |
   | ④ 診断アプリ完了 | 4 |
   | ⑤ CTAクリック | 5 |
   | ⑥ 申込み完了(CV) | 6 |

2. 人数の計算は、テーブルの中に埋め込まず、**`session_data`側にメジューとして分離**する

   ```dax
   人数 = SWITCH(
       SELECTEDVALUE(FunnelSteps[ステップ]),
       "① LP訪問", [総セッション数],
       "② 悩みセクション到達", SUM(session_data[reached_pain_section]),
       "③ 診断アプリ開始", SUM(session_data[diagnostic_started]),
       "④ 診断アプリ完了", SUM(session_data[diagnostic_completed]),
       "⑤ CTAクリック", SUM(session_data[cta_click]),
       "⑥ 申込み完了(CV)", SUM(session_data[conversion])
   )
   ```

3. `FunnelSteps[ステップ]`を選択し、「列ツール」→「列で並べ替え」で`順序`を指定し、人数の多い順ではなく手順順に固定する

**注意点**:`FunnelSteps`は静的なテーブルのため、**期間スライサーと連動しない**。ページ3(ファネル分析)には期間スライサーを置かない設計にしている。

## 3. 主要メジャー(DAX、修正版)

当初の設計書にあった`ALLEXCEPT`は不要だったため削除し、広告費0円のチャネルでCPAが「0」ではなく空欄になるよう修正している。

```dax
総セッション数 = COUNTROWS(session_data)

総CV数 = SUM(session_data[conversion])

CVR = DIVIDE([総CV数], [総セッション数], 0)

総広告費 = SUM(channel_ad_cost[monthly_ad_cost_jpy])

CPA = IF([総広告費] = 0, BLANK(), DIVIDE([総広告費], [総CV数], BLANK()))

診断開始率 = DIVIDE(SUM(session_data[diagnostic_started]), SUM(session_data[reached_pain_section]), 0)

診断完了率 = DIVIDE(SUM(session_data[diagnostic_completed]), SUM(session_data[diagnostic_started]), 0)

診断経由CVR = CALCULATE([CVR], session_data[diagnostic_completed] = 1)

非診断CVR = CALCULATE([CVR], session_data[diagnostic_completed] = 0)

CTAクリック率 = DIVIDE(SUM(session_data[cta_click]), [総セッション数], 0)
```

### 書式設定は「メジャー自体」に対して行う

%表示・桁区切りは、グラフごとに個別設定するのではなく、**データペインでメジューを選択→「測定値ツール」タブ→「書式」で一括設定**する方法に統一した。これにより、同じメジューを使うすべてのグラフ・テーブル・カードに自動で反映される。

| メジャー | 書式 |
|---|---|
| CVR / 診断経由CVR / 非診断CVR / 診断完了率 / 診断開始率 / CTAクリック率 | パーセンテージ・小数点以下1桁 |
| CPA / 総広告費 | 整数・桁区切りあり |

## 5. ブランドテーマ(1920×1080向けに文字サイズを拡大)

当初のテーマファイルは1280幅を想定した小さめの文字サイズだったため、1920幅用に拡大した`power-bi-theme.json`を作成した。

| 用途 | サイズ |
|---|---|
| カードの数値 | 48 |
| タイトル | 20〜36(部品による) |
| ラベル・軸 | 16〜18 |

**実装時のつまずき**:テーマJSONの中で、`textClasses`内の色は`"color": "#524E46"`のような文字列でよいが、`visualStyles`内の色は`{"color": {"solid": {"color": "#524E46"}}}`という**オブジェクト形式**にしないと、読み込み時に検証エラーになる。同じ「色」でも書く場所によって書式が異なる点に注意。

---

## 6. 実装時に判明した注意点(まとめ)

| 項目 | 内容 |
|---|---|
| リレーションの向き | チャネルを扱う視覚化は、必ず`channel_ad_cost[channel]`を使う。`session_data[channel]`だと広告費のフィルターが効かない |
| 日付の階層 | 日付フィールドは自動で階層化される。単体の`visit_date`を明示的に選び直さないと、月をまたいで日付が合算される |
| スライサーの高さ | 「間隔」スタイルのスライサーは、高さ96だとスライダーバーが表示されない。140以上を確保する |
| 複雑なDAXの貼り付け | `UNION`と`ROW`を組み合わせた複数行の数式は、チャットからの貼り付けで構文エラーが起きやすい。手入力+シンプルなメジューの組み合わせに切り替えると安定する |
| 書式設定の場所 | %表示・桁区切りは、個々のグラフではなく「メジャー自体」に設定すると、全体に一括反映されて効率的 |
| テーマJSONの色指定 | `textClasses`は文字列、`visualStyles`はオブジェクト形式、と書き方が異なる |
| CPAの扱い | 広告費0円のチャネルは、CPAを「0」ではなく空欄(BLANK)にする。「0円で獲得できている」という誤解を避けるため |
